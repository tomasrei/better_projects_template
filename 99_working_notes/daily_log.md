are working on: what you did, what you found, decisions and why, open
questions, things to check next. It is not about the template itself; how the
template works is described in `template_docs/`.

Add a new entry at the top for each day you work on the project. Other
project notes (meeting notes, ideas, to-dos) can go in this folder as separate
